## 实施步骤

1. 实现lookup输入→校验/身份→事务create-or-get→安全DTO。立即持久化，不等待AI或Anki。
2. 新记录投递enrich；重复记录返回现有内容/任务/异常状态，不重生成、不重置首次时间。
3. 新语境无条件建立新记录，不要求选择是否制卡。查询已排除/缺失/冲突的记录，不偷偷重建。
4. 实现显式编辑/重新生成/停止管理/恢复管理的业务函数；dirtyFields和generation与repo规则一致。
5. 设置未完成时照样可保存，后续首次设置能绑定之前未配置记录。
