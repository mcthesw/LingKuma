## 修改范围

## 实施步骤

1. 按base/desired/remote进行决策；desired从base原始字段加本地dirtyFields补丁构成，保留未编辑富文本。
2. 更新前持久化pendingWrite，调用updateNoteFields后读取核实；恢复先识别自己的未确认成功写入，再进行外部修改检测。
3. 每次确认只清除这次实际提交且当前仍相同的dirty字段；发送期间新编辑保留排队。
4. 外部修改保留两个版本并暂停；实现采用远端/采用本地/选择字段的业务接口，每次选择前再核实remote未改变。
5. 缺失记录只在显式recreate时重建；不读取/写入复习进度，不重建已有卡。

## 必须验证

- A24：本地编辑更新原note/card，复习信息保持不变。
- A25：远端修改、两边修改、富文本接受后无dirty循环。
- A26：update响应丢失不误判外部冲突，写入期间新revision不丢。
- A27：远端删除与noteId误指向不自动误写/重建。
