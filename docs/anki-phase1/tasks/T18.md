## 修改范围

管理页备份/恢复、schema校验和导入事务、测试。

## 实施步骤

1. 导出版本化结构：原始证据、材料、最小关联信息、可选受限媒体；明确这是本地摘录数据备份。
2. 排除密钥、完整设置凭证、活动锁和可重放pendingWrite；导出不能触发网络同步。
3. 导入校验schema/大小/身份一致性，按captureId去重；已有较新内容与差异不无条件覆盖。
4. 恢复后的关联先核实实际Anki，不盲信旧noteId/旧synced状态；不能重放备份时的写命令。
5. 导入失败可回滚并保留原库，迁移不删库重建；给出成功/重复/冲突/拒绝计数。

## 必须验证

- A44：导出无secret/lease/pendingWrite，恢复可读取。
- A45：旧备份不会覆盖新内容或复活Anki已删除记录。
- A46：损坏/超大/身份篡改备份拒绝且原数据不变。

## 明确禁止

不将备份实现成另一个多端实时同步系统，不把用户词库自动上传云端。
