## 修改范围

src/anki 的空运行时/桥接；构建配置、manifest 的必要改动；tests/anki。

## 实施步骤

1. 沿用原生 JS；建立新增代码的独立模块边界和唯一 content facade，不向网页 MAIN world 暴露接口。
2. 确保新增 bundle 隔离。不得把遗留大文件直接转 ES module 或全局切换 iife/module；记录实际采用的加载方式。
3. Chrome 后台和 Firefox 后台均正确且只加载一次新运行时；新增 alarms 权限（若原来没有），不扩大外部访问能力。
4. 增加最小测试命令：unit、integration、e2e 分开；测试依赖允许 fake-indexeddb 等，不引入应用框架。用 fake clock/fake transport 注入依赖。
5. 验证首次/二次 build 与 watch 重编译后产物仍存在，原高亮/查词能加载；检测遗留经典脚本全局符号没有被模块作用域变化破坏。
