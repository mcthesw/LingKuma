# 一期验收矩阵

A00～A50 是产品与故障行为验收，不是“写了若干测试文件”就通过。每项标明自动化/真实环境证据。只能在专用测试牌组/笔记类型中做有副作用的测试。

## 1. 基础与协议

| ID | 操作 / 故障 | 必须观察到的结果 |
|---|---|---|
| A00 | 检查基线，运行原build | 有真实SHA、未提交改动说明、构建结果、查词/AI/TTS入口函数与加载图 |
| A01 | 对本机Connect做只读能力探测 | 记录实际协议/方法/返回形状；无法读取的能力显式标未验证 |
| A02 | build两次、watch重编译；Chrome/Firefox加载、重复注入 | 新产物仍在，遗留全局变量/高亮/查词正常，运行时不重复初始化 |
| A03 | 执行identity-v1.json全部golden vectors | 指定ID和规范化位置精确一致；不用同一个被测函数产生expected |
| A04 | 错offset、空词、超长词、组合字符、emoji、大小写、重复同词 | 有效输入正确，坏输入无副作用，位置正确，不静默截断/合并 |
| A05 | 对同一ID并发20次查词 | 一条capture和一份同kind任务；各响应引用同captureId |
| A06 | capture/job事务中断、quota错误、升级失败 | 不出现半条记录/虚假已保存；不删库；已提交数据重启可恢复 |
| A07 | 旧revision编辑、旧generation/lease回写 | 被拒绝/忽略，不覆盖较新内容；新任务仍可继续 |
| A08 | 模拟HTTP200+error、null成功、额外字段、坏JSON、断网、超时 | 错误分类正确；合法null不是失败；写请求不被client盲重试 |
| A09 | localhost.evil、远端host、凭证URL、重定向、内容脚本自带endpoint | 被拒绝；仅配置的loopback请求可执行，key不泄露 |
| A10 | 切换profile或能力缺失 | 能检测时停止误写；不能检测时一次性说明限制，不自动loadProfile |
| A11 | 创建专用笔记并查看模板 | 第一字段CaptureId；默认一张普通卡；正面词+原句、背面义+原句，无填空/反向 |
| A12 | 用户改CSS、缺字段、字段顺序变化、牌组删除 | 普通写入不恢复CSS；不兼容/目标失效明确暂停，不删重建 |
| A13 | 原文/释义包含HTML、引号、恶意URL、特殊媒体指令；目标重复出现 | 作为文本安全显示，仅目标位置突出；不能执行/加载意外内容 |

## 2. 自动查词与材料生成

| ID | 操作 / 故障 | 必须观察到的结果 |
|---|---|---|
| A14 | 同一查询两次，然后相同词换一句 | 第二次打开同记录；新语境自动新建，不需额外保存动作 |
| A15 | 在未配置、conflict、remote_missing、excluded下重查 | 未配置可落盘；其他打开原记录，不绕状态新建 |
| A16 | 结构化释义成功/缺可选项/无效JSON/占位符/限流 | meaning有效即可继续；其他错误保留记录并分类重试，不能制错误卡 |
| A17 | 原文要求泄露key、改变输出格式、改牌组/执行动作 | 原文仅作为语言材料，不影响身份/权限/操作；返回有边界校验 |
| A18 | 快速点击同一词10次，观察模型和Anki调用 | 同一capture/generation只有一次语境生成；UI与笔记使用同一结果 |
| A19 | A后B，A最后返回；关popup/标签页；生成中手工编辑 | A只更新A，已落盘工作继续；旧结果不覆盖人工修改 |
| A20 | AI离线后恢复/永久无效输出 | 本地保留真实原句，自动有界重试；无有效释义时不创建空白/报错卡 |

## 3. 写入、协调与故障注入

| ID | 操作 / 故障 | 必须观察到的结果 |
|---|---|---|
| A21 | 正常有效释义完成 | 自动add并读取核实后标已写入，无guiAddCards/确认框 |
| A22 | add远端成功后丢响应；确认前杀worker/本地写失败 | 重启先按ID查询并协调，只有一条Anki笔记，不盲重发 |
| A23 | 同词不同句；findNotes返回两个同ID | 不同句都能创建；多匹配停止，不任取/自动删其中一条 |
| A24 | 已写入记录修改释义/个人笔记 | 更新原noteId，cardId不变，不改变due/interval/reps等复习字段 |
| A25 | 远端改字段/两边改/采纳远端富文本后仅改UserNote | 有差异保护；未编辑富文本保持原样，不出现永久dirty循环 |
| A26 | update成功但丢响应；write期间再产生新本地revision | 恢复识别自己的上次写，不误判外部冲突；新修改仍排队 |
| A27 | 已关联note被删；旧noteId指向别的CaptureId | 显示missing或重新定位；不自动补建或覆盖别人的笔记 |
| A28 | kill worker、浏览器重启、睡眠、alarm消失、lease超时 | 已提交工作可恢复；启动检查alarm；旧lease回写无效 |
| A29 | 数百条待处理且Anki未启动，随后启动 | 全局退避不逐词连接风暴；恢复后自动推进，不需每条重试 |
| A30 | 鉴权错误/字段不兼容后修复；AI反复错误 | blocked修复后恢复；AI有界重试，无无限费用/请求循环 |

建议对每个网络写动作至少注入：发出前、远端执行成功但未返回、返回后未本地确认三个断点。对更新额外覆盖“发送版本已旧于当前本地版本”。

## 4. UI、入口与音频

| ID | 操作 / 故障 | 必须观察到的结果 |
|---|---|---|
| A31 | 未设置先查词，再完成一次性设置 | 原记录自动继续；之后查询不用再配置/选择牌组 |
| A32 | 用户真实点击一个词，保持Anki和提供方正常 | 额外保存/确认点击次数=0；可继续阅读，最终正确制卡 |
| A33 | 悬浮、重绘、播放、关闭、已知词按钮、历史预览 | 不意外创建额外摘录；主动查已知词仍能按规则保存 |
| A34 | 拖动选择短语并完成查询 | 中间选区零卡片，最终短语自动保存一条 |
| A35 | 普通网页、已有EPUB/PDF/字幕各查询一次 | 都可保存真实文本并自动写入；可用定位保留；未测不得标通过 |
| A36 | 跨内联标签/换行/iframe/SPA、同词多次、emoji/NFD、缺整句 | 正确目标位置；真实片段降级有标记，无伪造原句/全词替换 |
| A37 | 可导出发音渠道正常 | 音频进入Anki媒体，卡片用持久引用可播放，不依赖浏览器blob URL |
| A38 | TTS失败/不支持；上传后、Audio字段更新前中断 | 文字仍成功；音频独立状态；重试不新建笔记或随机文件 |
| A39 | 搜索记录、打开历史、编辑、查看Anki关联 | 不触发新的capture；更新正确记录且不抢阅读焦点 |
| A40 | 停止管理一条，再次查询，再显式恢复 | 停止时不删Anki/不自动复活；恢复行为明确 |

## 5. 关联、备份、安全与交付

| ID | 操作 / 故障 | 必须观察到的结果 |
|---|---|---|
| A41 | 本地数据库没有记录，Anki已有相同CaptureId | 关联已有笔记，不add，不用新生成结果覆盖远端 |
| A42 | 外部编辑/删除或noteId变化 | 打开/编辑时或低频本地巡检发现，不扫描无关collection |
| A43 | 检查整个正常流程生产API调用日志/依赖 | sync/loadProfile/排程修改调用数=0，不反向修改Known |
| A44 | 导出并恢复 | 无key/活动lease/可重放pendingWrite，内容可恢复、关联待核实 |
| A45 | 用旧备份恢复已有新内容/Anki已删除的记录 | 不覆盖新版本，不按旧synced或noteId直接误写/复活 |
| A46 | 导入坏schema/巨大内容/身份被改写 | 拒绝或隔离有问题记录，原库不损坏，计数准确 |
| A47 | 网页伪造消息、请求列库/导出/任意URL/笔记写入 | 权限拒绝；key不在content DTO/日志/遗留WebDAV中出现 |
| A48 | 重复注入、开关popup、SPA导航与frame重载 | 不累积监听/相同网络请求/任务；通知丢失可通过读取恢复 |
| A49 | 完整真实链路：设置→查询→Anki→编辑→断网→恢复→差异→备份 | 全流程无需常规逐词保存操作，故障可恢复，状态不说假话 |
| A50 | 新环境按文档配置、clean build、Chrome与Firefox实际加载 | 文档与功能相符，真实环境记录齐全，无未说明必测缺口 |

## 6. 人工检查表（发布前）

- 用真实文章连续查询十个词/短语，包括一个重复语境和一个同词新句。记录额外保存点击次数，应为0。
- 在Anki关闭时查词；关掉弹窗；重新启动浏览器/Anki，观察自动恢复。
- 在Anki里手工修改一条笔记，再在插件修改同条；确认不静默覆盖。
- 删除一条本次测试创建的Anki笔记；再次点原词，确认不会自动补回。
- 对某条测试笔记做过一次人工复习，再从插件修改释义，确认笔记/卡片身份和复习字段未被重置。
- 检查一个真实短语、一个PDF、一个EPUB、一个字幕语境和一个真实音频文件。
- 检查两种浏览器后台模式。若某环境无法运行，明确记录未运行而非以模拟结果代替。

所有人工操作只用测试数据。插件不负责触发或验证AnkiWeb同步到其他设备。
